# Specification

## Summary
**Goal:** Build a single, polished Home/front page for a modern creative digital agency site (Renev-inspired) with section-based layout, consistent theme, and on-page navigation.

**Planned changes:**
- Implement a single-page Home layout with clearly separated sections (Hero, plus at least 4 additional sections, and a Footer) with English marketing copy.
- Add a sticky/on-page header navigation using anchor links to smoothly scroll to sections, including an active-section indicator while scrolling.
- Define and apply one cohesive visual theme (typography, spacing, colors, buttons, cards) that is responsive on mobile and desktop.
- Add modern UI interactions (hover/pressed states) and subtle scroll-reveal animations for major sections.
- Drive key sections (e.g., services, featured work, testimonials, stats) from reusable centralized data structures (arrays/objects).
- Add basic SEO and accessibility: semantic heading hierarchy, appropriate alt text, and meta title/description for the Home route.
- Use locally generated static images from `frontend/public/assets/generated` in the Hero and other key sections (portfolio thumbnails, testimonial avatars).

**User-visible outcome:** Users see a single, modern agency-style landing page with smooth in-page section navigation, consistent styling, subtle animations, and local imagery (no additional pages/routes).
